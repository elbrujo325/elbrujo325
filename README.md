## Research highlight

> **Thesis result, stated honestly.** For Sgr A\*, the charged model improves the fit by Δχ²/ν = −4.32 over Schwarzschild; for M87\* it gets worse (+10.74) because the 1D symmetric model ignores jet emission. My conclusion: the Sgr A\* gain is a **scale effect**, not a detection of charge, given the ~11.8 % uncertainty in the mass-to-distance ratio.
